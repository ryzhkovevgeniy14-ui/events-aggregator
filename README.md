# Events Aggregator

## Запуск

Приложение запускается через FastAPI.

При старте приложения в `lifespan` автоматически запускаются фоновые задачи:
* синхронизация событий;
* Outbox Worker для обработки ожидающих событий Outbox.

Outbox Worker работает в том же процессе, что и основное FastAPI-приложение, в виде отдельной асинхронной задачи.
